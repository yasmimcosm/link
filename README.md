# 🌿 Mini Portfólio Pessoal — Yasmim Silva Cosme

🎨 Página pessoal desenvolvida com **HTML e CSS**, com uma estética **delicada e botânica**, inspirada em ilustrações flat de lírio-do-vale, em tons de verde-sálvia e menta.
O projeto funciona como um **hub de links profissionais**, reunindo redes sociais, currículo acadêmico e contato.

---

## ✨ Visão Geral

Este mini portfólio foi criado para apresentar, de forma simples e elegante, informações profissionais e acadêmicas, com foco em:

* Identidade visual forte e coerente
* Layout limpo e responsivo
* Formas arredondadas e interações suaves
* Experiência agradável em diferentes dispositivos

---

## 🚀 Como Visualizar o Projeto

### Opção 1 — Abrir localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/yasmimcosm/links
   ```
2. Abra o arquivo `index.html` no navegador

### Opção 2 — GitHub Pages (se ativado)

Acesse diretamente pelo link:

```
https://yasmimcosm.github.io/links
```
